# E-Commerce Database (MySQL)

## Overview

This project demonstrates the design and implementation of a relational database using **MySQL**. The database models a simple e-commerce system with **Customers, Products, Categories, Orders,** and **OrderDetails**.

The project demonstrates fundamental database design concepts, SQL programming, relational data modeling, and data retrieval techniques commonly used in business applications.

---

- MySQL Workbench
- SQL
- Git
- GitHub

---

## Project Features

- Designed and implemented a relational database for an e-commerce system.
- Created database tables using SQL Data Definition Language (DDL).
- Established relationships using primary and foreign keys.
- Inserted sample business data into the database.
- Executed SQL queries to retrieve, filter, sort, and summarize data.
- Documented and version-controlled the project using Git and GitHub.

---

## Database Tables

| Table        | Description |
|--------------|-----------------------------------------|
| Customers    | Stores customer information.            |
| Categories   | Stores product categories.              |
| Products     | Stores product information.             |
| Orders       | Stores customer orders.                 |
| OrderDetails | Stores products included in each order. |

## How to Run

1. Open **MySQL Workbench**.
2. Open **ECommerce_DB_MySQL.sql**.
3. Execute the SQL script.
4. The database and tables will be created automatically.
5. Run **sample_queries.sql** to explore the database.
